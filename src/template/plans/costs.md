# Costos

Estructura de costos de **operar** el proyecto en producción — no de desarrollarlo. Sirve para que un agente entienda el impacto económico antes de proponer algo que dispare más consumo (ej. subir el tamaño de una instancia, llamar más seguido a una API de terceros, agregar un servicio nuevo).

Si un costo ya está documentado en detalle en `external/<servicio>.md` (ej. el pricing de una API específica), no lo dupliques acá: menciónalo brevemente y linkea.
